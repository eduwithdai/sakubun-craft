## 使い方の説明文（紹介記事用）

**STEP 1　学年をえらんでスタート**
最初の画面で学年（1〜6年）を選び、「スタート」を押します。文は、その学年までに習う漢字で表示されます。まだ習っていない漢字はひらがなになります。初めて開いたときはオープニングと使い方の説明が流れ、「つぎから みない」を選ぶと次からは出ません。

**STEP 2　ことばブロックを知る**
作文の書き出しの型が、18種類の「ことばブロック」になっています（場面、気持ち、会話、五感、なぞ、ことわざなど）。ブロックをタップすると、ブロックを使わない書き出しと使った書き出しを並べて比べられます。れいの文は読み上げもできます。

**STEP 3　石をほってブロックを見つける**
「ブロックを ほる」を押し、石を4回タップしてくだくと、ブロックが1つ出てきます。まだ使っていないブロックが出やすくなっています。出てきたブロックは、そのままクラフトに使えます。

**STEP 4　クラフトだいで書き出しをつくる**
1. 「なにを書く？」で書くテーマを選びます（遠足、運動会、給食、家族、本を読んでなど13種類）。
2. 思い出しのヒントを見ながら、「ざいりょう」の欄に言葉を入れます。れいの文は、選んだテーマに合わせて変わります。
3. 入れた言葉が、その場で原稿用紙に文としてできあがります。「たて書き」にすると、原稿用紙のきまりどおりに表示されます。
4. 言葉のつなぎ目が重なったところ（「音がが」など）や、よくある書きまちがい・漢字の変換ミスは自動で直り、直したところが表示されます。

**STEP 5　自分のせかいにつみあげる**
「クラフト！」を押すと完成です。「つくってみて、どうだった？」で、「すらすら つくれた／少し むずかしかった／もっと つくりたい」からふり返りを選びます。つくった書き出しはブロックになり、「わたしのせかい」に積み上がっていきます。ブロックをタップすると、書いた文の読み上げとコピーができます。
